For the dependency oracle, the sandbox harness compiled the three dependency source strings extracted from the exact Standard JSON input with its optimizer, EVM target and IR settings. It invoked the harness through loopback Anvil `eth_call` with a runtime state override. The run passed 8,927 nonzero bit vectors and 2,006 `mulDiv` vectors, including 2,003 products wider than 256 bits. It checked all eight odd inverse-seed classes modulo 16 and the zero index, zero denominator and overflowing quotient rejections. Expected values came from JavaScript `BigInt` division and bit lengths. For bit vectors, sweep every nonzero byte at each of 32 byte offsets and add each power of two's adjacent values and high-set-bit variants. For division, use the SHA-256-derived `a`, `b` and `r` of `RMT-dependency-oracle-${3*i + offset}` for `i` in `[0, 2000)` and offsets 0 through 2. With `U=2**256-1` and `hi=(a*b)>>256`, form `d=hi+1+r%(U-hi)` and compare the exact floor and ceiling. Add boundary products `(U,U,U)`, `(U,1,1)`, `(U-1,U-1,U)`, `(2**240,2**120,2**106)`, `(0,U,U)` and `(9,2,6)`. The syntax and arithmetic evidence address the four warnings.
