# Upstream source archival notices

Only the archived public-source responses and excerpts contain upstream source; none is imported into production RMT contracts. All explicit SPDX declarations in the captured responses are MIT. Six transitive `lib/tm-core-lib` source files omit SPDX headers: `ERC165.sol`, `IERC165.sol`, `StorageTstorish.sol`, `EnumerableSet.sol`, `IEOARegistry.sol` and `ITransferValidator.sol`. Their original bytes and metadata hashes are retained as research evidence; do not infer a missing file-level license, historical dependency revision or authorization to reuse them in a production compilation. The direct public upstream tm-core-lib LICENSE URL returned404; no authenticated access was attempted. This transitive license/provenance limitation remains part of the unadmitted validator closure.

These are current upstream license notices retained alongside the exact source-response hashes; the current license URLs do not establish a historical git commit or independently compiled runtime. Original file-level notices remain in the raw archive.
