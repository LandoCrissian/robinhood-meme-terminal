# GitHub Sponsors profile

This is the canonical public positioning for RMT's GitHub Sponsors profile.

## Profile introduction

### Help build a safer, more useful Robinhood Chain terminal

Robinhood Meme Terminal (RMT) is an independent, non-custodial discovery and
trading terminal for Robinhood Chain.

RMT brings external markets, verified project origin, live metadata, holder and
contract evidence, sell-direction simulation, and in-terminal wallet execution
into one mobile-first product. The goal is straightforward: help users discover
what is trading, understand what they are signing, and keep control of their
funds.

Sponsorship helps fund production infrastructure, monitoring, security testing,
integration research, mobile reliability, public documentation, and preparation
for independent review.

Sponsors support the work; they do not purchase influence. Sponsorship does not
provide a token allocation, investment return, revenue share, priority listing,
favorable risk label, partnership status, or control over RMT.

- Live product: [www.rmtlaunch.fun](https://www.rmtlaunch.fun/)
- Status: [www.rmtlaunch.fun/status](https://www.rmtlaunch.fun/status)
- Risks: [www.rmtlaunch.fun/risks](https://www.rmtlaunch.fun/risks)

RMT is independent software and is not Robinhood Markets, Inc.
