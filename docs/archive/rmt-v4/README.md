# Archived RMT V4 product generation

RMT V4 is retired and is not part of the current public product or V7 direction.

- The V4 infrastructure contracts were deployed.
- One explicitly disposable operator smoke token was used to prove the bounded launch, buy, sell, and reward-claim loop.
- No community or public project launched through RMT V4.
- RMT V4 is not selectable in the public application and its records do not appear as current RMT markets.
- The legacy factory remains referenced only where later factories preserve name and ticker history.

The records in this directory are immutable historical evidence:

- [Deployment and smoke-test record](MAINNET_DEPLOYMENT.md)
- [Contract manifest](MAINNET_CONTRACTS.md)

“RMT V4” means the retired fourth RMT product generation. It must not be confused with **Uniswap v4**, the current external DEX protocol used by eligible RMT trading and V6 graduation routes.
